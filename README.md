# Chemistry-Phase-Change-Simulator-Copy
This simulator works with pygame and python to simulate multiple substances' states of matter at differed temperatures.
Features

Adjustable temperature from 0 to 1,000 Kelvin

Water, oxygen, and neon simulations

Phase transitions based on freezing and boiling points

Animated particle movement for different states of matter

Technologies

Python, Pygame

Project Status

Educational prototype.

Limitations

Particle movement uses simplified rules and is not intended as a scientifically precise molecular dynamics simulation.
